# TTS-Soundboard
An app to design custom Text-To-Speech voice profiles for software and games. 
- Create the 'timbre' of your TTS voice
  - Human - English (for now) of various accents and pitches. 
  - Non-Human - Alter TTS Timbres with synthesizers, modulators, and other effects (akin to guitar pedal making, but like a parametric dashboard)
- (optionally) create a dialogue library hash table for games that associates lines, .wav (or other) sound files, dialogue categories, calling events, and more.
  - create a "master table" where all characters' dialogue asset tables feed into, allowing specific dialogues to be linked via calling events to create semantic dialogue maps.
